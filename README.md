## Resumo dos Conceitos Praticados

[Resumo dos Conceitos Praticados

Durante a realização destes desafios no freeCodeCamp, foram praticados os conceitos fundamentais do HTML5 e a estrutura básica de páginas web. O foco principal esteve na marcação semântica de textos utilizando cabeçalhos (<h1> a <h3>) e parágrafos (<p>), no uso correto de elementos auto-fecháveis (void elements) como a tag <img>, e na estruturação de mídias com a tag <figure>. Além disso, foi essencial compreender a função dos atributos HTML — como src para fontes de mídia e alt para acessibilidade e descrição de imagens.

As principais dificuldades encontradas envolveram a depuração (debugging) de erros comuns de sintaxe em HTML, tais como o uso incorreto de nomes de tags inexistentes e a substituição inadvertida de atributos (por exemplo, confundir href com src ou att com alt). A superação desses desafios permitiu consolidar uma atenção maior aos detalhes da sintaxe e reforçar as boas práticas de acessibilidade e semântica na web.]
